# Data Backup 项目协作状态

## 项目简介

Data Backup 是面向个人桌面用户、以 macOS 为首发平台的数据备份软件。当前处于需求与逻辑架构完成、进入架构验证之前的阶段，尚未初始化产品代码工程。

## 当前基线

- 产品需求和 20 个用例已经结构化，并可生成 Markdown、UML 和课程报告内容。
- C1、C2、关键容器 C3、部署、逻辑类图及三个关键顺序图统一由 `docs/c4/model.yaml` 生成。
- 压缩、认证加密、打包、文本密钥文件、本地/WebDAV/S3 仓库均已形成逻辑设计约束。
- 下一步是为高风险决策建立可执行探针和先失败的验收测试，再初始化最小 Rust 核心。

## 事实来源

需求以 `docs/requirements/use-cases.yaml` 为准，架构以 `docs/c4/model.yaml` 为准，技术决策以 `docs/decisions/` 为准。`docs/report.docx` 是课程报告的直接排版基准，生成器只能修改需求分析和系统设计目标区域，不得全局重设字体或封面格式。

## 工作方式

从最新 `main` 创建短期分支，每个分支在 `docs/collab/` 下保留同名进度文档。变更遵循 Red、Green、Refactor；未来测试层次为 C1 端到端、C2 集成、C3 构件和 C4 单元测试。当前文档工具测试属于生成器单元与集成回归。

本地 CI 命令：

```shell
uv run scripts/check.py
```

仓库已有远端但未配置 GitHub Actions，因此当前只维护本地 CI，不配置 CD。

## 后续计划

1. 完成仓库格式、原子提交、故障清理和内容寻址探针。
2. 先定义筛选与本地备份的行为规格及集成测试。
3. 初始化最小 Rust 核心并形成可验证的本地备份闭环。
4. 在核心稳定后依次实现恢复、保留、守护进程、CLI 和 GUI。
