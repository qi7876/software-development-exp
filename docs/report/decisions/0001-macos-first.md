# ADR-0001：macOS 作为首发平台

- 日期：2026-09-04
- 状态：已接受

## 背景

守护进程、自启动、文件权限、通知、文件系统元数据和应用签名均具有平台差异。项目由一人敏捷开发，同时支持多个桌面平台会显著增加验证矩阵并削弱恢复可靠性的投入。

## 决策

首个可发布版本以 macOS 为唯一承诺平台。Rust 核心保持平台边界清晰，不主动使用无法封装的 macOS 专有语义；其他平台在核心闭环稳定后逐步验证。

最低 macOS 版本在桌面壳、系统服务和安装包原型完成后确定。

## 后果

- 第一阶段只需维护一套安装、自启动、通知和恢复验收流程。
- 可优先正确处理 macOS 的符号链接、权限、扩展属性和应用沙箱限制。
- Windows 和 Linux 用户暂不在发布支持范围内。
- CI 仍可在成本合理时编译平台无关的 Rust 核心，避免不必要的平台耦合。

## 验证方式

- 在支持的 macOS 最低版本和当前版本上完成安装、升级、自启动和卸载测试。
- 完成外接磁盘离线、权限失败、睡眠唤醒及进程中断恢复测试。
