# ADR-0009：文件筛选规则语义

- 日期：2026-09-04
- 状态：拟议，等待扫描原型验证

## 背景

用户需要按路径、所有者、用户组、时间和文件类型决定备份范围。规则如果缺少明确的路径基准、组合顺序或时间语义，会导致预览与实际备份不一致，甚至在用户不知情时遗漏文件。

## 拟议决策

### 规则模型

- 每条规则包含动作（include/exclude）和若干条件；同一规则内条件为 AND，不同规则按顺序匹配。
- 最后一个匹配规则决定结果，便于先排除大目录再重新包含其中少量文件。
- 默认包含普通文件、目录和符号链接；socket、FIFO、块设备和字符设备默认排除。
- 规则相对于每个备份源的逻辑根目录计算，不匹配绝对路径，防止任务迁移后规则失效。
- 保存任务前编译全部规则，错误规则不能启用。

### 支持条件

| 条件 | 第一阶段语义 |
| --- | --- |
| 路径 glob | 默认方式；支持 `*`、`?`、字符类和跨目录 `**`，匹配规范化相对路径 |
| 路径正则 | 高级方式；使用 Rust `regex` 语法，不支持回溯引用和环视；限制表达式大小 |
| 所有者 | UI 显示用户名，规则持久化 macOS 数值 UID；无法解析时仍显示数值 |
| 用户组 | UI 显示组名，规则持久化 macOS 数值 GID；补充组成员关系不参与文件所有组判断 |
| 修改时间 | 支持早于、晚于和区间；比较文件 `mtime` |
| 创建时间 | macOS 支持 birth time；目标平台不可用时规则验证失败而非静默改用 `ctime` |
| 相对时间 | 如“最近 30 天”；以本次运行开始时刻计算，并把实际截止时刻写入运行记录 |
| 扩展名 | 不区分大小写的可配置集合；无扩展名是独立条件 |
| 对象类型 | 普通文件、目录、符号链接、硬链接及特殊文件类别 |
| 文件大小 | 支持大于、小于和闭区间，单位在配置中保存为字节 |
| 隐藏属性 | macOS Finder 隐藏标志和点文件分别可选，避免混为一种语义 |

MIME/内容嗅探不进入第一阶段：它需要读取文件内容、会降低扫描性能，而且识别结果不稳定。后续若加入，必须作为独立显式条件，不能替代扩展名规则。

### 预览与可解释性

- 任务编辑器提供 dry-run，列出包含数、排除数、预计字节数和部分匹配样本。
- 每个样本显示最终决定规则及条件，用户可以解释“为什么被排除”。
- 预览和正式备份调用同一筛选库；运行记录保存规则集版本和相对时间截止点。
- 目录被排除时，只有在能够证明后续规则不会重新包含其后代时才允许剪枝。
- 规则变化只影响新快照，不回溯删除旧快照中的文件；旧内容仍按保留策略管理。

## 风险与验证

- 使用 Unicode 组合字符、大小写差异、点文件、符号链接环和无权限目录构造 macOS 测试集。
- 对十万级路径和大量规则执行性能测试，限制编译大小和扫描时间。
- 对用户名/组名变更、UID/GID 不存在及从另一台 Mac 恢复进行测试。
- 用属性测试证明预览和正式扫描在相同文件系统快照上结果一致。
- UI 必须在启用规则前展示匹配示例和错误位置。
